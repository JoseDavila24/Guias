# 7.4.2 LAB – IMPLEMENT DHCPV4

## R1
```
hostname R1
no ip domain-lookup
```

### Configure Inter-VLAN Routing on R1
```
interface GigabitEthernet0/0/1
no shutdown
exit

interface GigabitEthernet0/0/1.100
description Client Network
encapsulation dot1q 100
ip address 192.168.1.1 255.255.255.192

interface GigabitEthernet0/0/1.200
encapsulation dot1q 200
description Management Network
ip address 192.168.1.65 255.255.255.224

interface GigabitEthernet0/0/1.1000
encapsulation dot1q 1000 native
description Native VLAN
```

**COMPROBAR (show ip interface brief)**

```
interface GigabitEthernet0/0/0
ip address 10.0.0.1 255.255.255.252
no shutdown

ip route 0.0.0.0 0.0.0.0 10.0.0.2
```

### DHCP Configuration
```
ip dhcp excluded-address 192.168.1.1 192.168.1.5

ip dhcp pool R1_Client_LAN
network 192.168.1.0 255.255.255.192
domain-name ccna-lab.com
default-router 192.168.1.1
lease 2 12 30

ip dhcp excluded-address 192.168.1.97 192.168.1.101

ip dhcp pool R2_Client_LAN
network 192.168.1.96 255.255.255.240
default-router 192.168.1.97
domain-name ccna-lab.com
lease 2 12 30
```

**VERIFICAR**
```
show ip dhcp pool
show ip dhcp bindings
show ip dhcp server statistics
show ip dhcp
show ip dhcp server
```

## R2
```
hostname R2
no ip domain-lookup
```

### Configure G0/0/1, G0/0/0 and static routing
```
interface GigabitEthernet0/0/1
ip address 192.168.1.97 255.255.255.240
no shutdown
exit

interface GigabitEthernet0/0/0
ip address 10.0.0.2 255.255.255.252
no shutdown

ip route 0.0.0.0 0.0.0.0 10.0.0.1
```

### Configure DHCP relay agent
```
interface GigabitEthernet0/0/1
ip helper-address 10.0.0.1
end
write memory
```

## S1
```
hostname S1
no ip domain-lookup
```

### Create VLANs
```
vlan 100
name Clients
vlan 200
name Management
vlan 999
name Parking_Lot
vlan 1000
name Native
exit
```

### Configure management interface
```
interface vlan 200
ip address 192.168.1.66 255.255.255.224
no shutdown
exit
ip default-gateway 192.168.1.65
```

### Configure unused ports to Parking_Lot VLAN and shutdown
```
interface range fastEthernet 0/1-4, fastEthernet 0/7-24, gigabitEthernet 0/1-2
switchport mode access
switchport access vlan 999
shutdown
exit
```

### Configure client port
```
interface fastEthernet 0/6
switchport mode access
switchport access vlan 100
```

**VERIFICAR (show vlan brief)**

### Configure trunk port
```
interface fastEthernet 0/5
switchport mode trunk
switchport trunk native vlan 1000
switchport trunk allowed vlan 100,200,1000
exit
copy running-config startup-config
```

**VERIFICAR (show interfaces trunk)**

## PREGUNTAS

**Why is interface F0/5 listed under VLAN 1?**  
Port 5 is in the default VLAN and has not been configured as an 802.1Q trunk.

**At this point, what IP address would the PC's have if they were connected to the network using DHCP?**  
They would self-configure with an Automatic Private IP Address (APIPA) address in the 169.254.x.x range.
